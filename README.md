# 🛠️ Handyman App

Plataforma web enfocada en la gestión y solicitud de servicios técnicos de plomería y electricidad.

## 🚀 Características
- Catálogo de servicios técnicos interactivo.
- Enlace directo de cotización e integración vía WhatsApp.
- Diseño limpio y responsivo impulsado por Tailwind CSS.

## 🛠️ Tecnologías
- **HTML5**
- **Tailwind CSS**
- **JavaScript**
- **GitHub Codespaces**
- **Netlify**
